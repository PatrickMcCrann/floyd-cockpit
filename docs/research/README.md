# Research trail

The work that happened before a line of code was written: who The F Suite's
members are, ten candidate problems ranked, every one vetted against the live
vendor landscape, and the reasoning that killed four of them and promoted the
one that got built.

Narrated in `../07-chat-history.md`, Part 1, Turns 1–6.

## Files

| File | What it is |
|---|---|
| `fsuite-icp-and-options-report.md` | The F Suite ICP and membership segments, then ten prototype options scored on value, demo-ability, buildability, whitespace and Floyd fit |
| `vendor-vetting-addendum.md` | Each option checked against shipping products. Four died on duplication; the table names the vendor that killed each one |
| `idea-ledger.md` | The decided build with its scope cuts, positioning lines, reserve options, ideas absorbed as features, and the retired list |
